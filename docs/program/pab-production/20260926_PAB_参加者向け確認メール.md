## この文面の考え方

**変更点を隠さず、でも冒頭には置いていません。** 件名には入れて気づいてもらいつつ、本文は「日時・場所 → 流れ → 変更点」の順にしました。すでに申し込んだ方がいちばん知りたいのは「いつ・どこ」だからです。

**終了時刻の変更は理由を添えました。** 「ごあいさつの時間が増えたため」と一言あるだけで、運営の都合に振り回された感じが薄れます。

**撮影は独立した見出しにしました。** 申し込みの時点でご案内できていなかったので、さらっと流さず、受付でお申し出いただければ配慮する、とはっきり書いています。

**転送のお願いは最後に置きました。** 先に置くと「宣伝メール」に見えます。当日の案内をひととおり読んだあとなら、素直に受け取ってもらえます。

**ハラスメントのくだりは「みなさんに守っていただくこと」という書き方にしていません。** 「参加するみなさん・講師・スタッフの全員が安心して過ごせる場にしたい」と、**主語を全員にしています。** 参加者にだけ規律を求める形にすると、身構えさせてしまいます。同じガイドブックを講師にもお送りするので、書いていることと実際が一致します。
