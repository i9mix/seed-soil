## 4. 会場レイアウト（701会議室）

### 4-1. 二つのモード

**［モード A］座談会モード（10:30〜12:40）**
- テーブルは島配置のまま、**椅子だけを前方に寄せて前向きに整列**
- 前方に登壇席（最大3名＋モデレーター）・スクリーン・演台
- 中央通路と後方の入退場導線を確保（途中入退場に対応）

**［モード B］島モード（12:45〜終了）**
- 椅子をテーブルに戻すだけ。テーブルは動かさない
- 島は**ワークショップの職能単位**で構成
  - 劇作：20名 → 4〜5卓
  - 演出：10名 → 2〜3卓
  - プロデューサー：20名 → 5卓（4人前後×5チーム）
- 座談会のみ参加の方の席は、ランチ以降は**後方に集約**

### 4-2. 島の配置（音対策込み）

**パーテーションがないため、島の物理的な置き方が音対策のほぼすべてになる。**

```
          [ スクリーン・登壇席 ]

  ┌──────────────┐   ┌──────────────┐
  │  演出（10名）      │   │  劇作（20名）      │  ← 最奥・静かな側
  │  2〜3卓            │   │  4〜5卓            │
  └──────────────┘   └──────────────┘

              ← 通路を広く空ける（緩衝帯） →

  ┌──────────────────────────────┐
  │      プロデューサー（20名）5卓              │  ← 入口側・議論が最も大きい
  └──────────────────────────────┘

          [ 入口・受付 ]
```

- **劇作WS＝静かな執筆** → 入口から最も遠い最奥に
- **プロデューサーWS＝議論＋プレゼン練習で最も音が出る** → 入口側、劇作から対角に
- **演出WS＝議論中心・10名で最小** → 中間
- **劇作／演出とプロデューサーの間に通路を広く取り、緩衝帯にする**（パーテーションの代わり）
- 島は**背中合わせにせず、向きを揃える**（声が互いに正面から飛ばないように）

## 5. 同室並行WSの音対策（パーテーションなし・再構築）

遮蔽物が使えないため、**「拡声しない」の徹底が唯一かつ最大の対策**になる。ここが崩れると45分間ずっと音量競争になり、劇作WSの執筆が成立しない。

| 優先度 | 対策 | 内容 |
|---|---|---|
| **★最重要** | **拡声しない** | 各WSでハンドマイクを一切使わない。ファシリの地声で届く島間隔にする。**1つでも拡声すると他2本が対抗して拡声する**。ブリーフィングで全ファシリに明言する |
| **★最重要** | **アナウンスは横堀に一本化** | 「残り5分」等の合図は横堀が1回だけ全体に出す。各WSが個別に大声を出さない |
| ★ | **物理距離と緩衝帯** | §4-2のとおり、劇作とプロデューサーを対角に置き、間の通路を広く空ける |
| ★ | **プレゼン練習をホワイエへ逃がす** | プロデューサーWSの2分プレゼン練習を廊下・ホワイエに出す【要確認：論点#5】。**パーテーションがない以上、これが最も効く代替手段**。可否を必ず事前に確認したい |
| ○ | ホワイトボード／掲示パネルの持ち込み | 借りられれば島の間に立てる【要確認：論点#4】。パーテーションほどの効果はないが、視線が切れるだけでも集中は上がる |
| ○ | **劇作WSの設計を音前提にする** | 阿部さんに「周囲に音がある環境での執筆」を前提に進め方を組んでもらう。個人執筆よりグループでの声出し中心のほうが、この環境では成立しやすい |
| — | **BGMは流さない** | マスキング目的のBGMは、かえって全体の声量を上げるため使わない |
| ★ | **リハで検証** | 仕込み時（09:50–10:00）に鈴木・佐々木・大野が各島で通常の声量で話し、被り具合を実地確認する。**ここで無理と判断したら、その場でプロデューサーWSをホワイエに出す**判断をする |

| **申込データの管理者が当日不在** | 受付で想定外のケースが出たとき | §6-4のとおり、①判断基準を事前に文書化して大野へ委譲 ②名簿を紙で用意 ③髙田は遠隔待機。**この3点が揃っていないと開場直後に受付が止まる** |
| **統括とMCを分けたことによる連携ミス** | 座談会の転換や押し戻しの判断時 | 野村（統括）と横堀（MC）が**押したときの判断を事前にすり合わせておく**。判断は野村、伝達は横堀と役割を明確に |
