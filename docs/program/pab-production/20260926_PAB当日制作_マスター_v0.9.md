### この設計を成立させている3つの判断

**① テーブルは終日動かさない。転換は椅子だけ。**
仕込みの時点でテーブルを島配置で確定させ、座談会中は椅子だけを前方に寄せて前向きに並べる（＝視覚的にはシアター形式）。転換は「椅子をテーブルに戻す」だけで5分。テーブルの大移動をやると10〜15分かかり、終了がさらに後ろへずれる。

**② 参加者は最初から職能別の島に座る。**（9/11に追加）
ワークショップは45分しかない。そこで自己紹介から始めると手を動かす時間が残らない。だから**受付の時点で島番号までご案内し、ランチ中に講師を交えて自己紹介を済ませてしまう**。午前と午後で座席が変わらないので、転換も「椅子を戻すだけ」で済む。①と噛み合っている。

**③ 司会と制作統括を分けない。**（9/11に変更）
v0.8までは「統括＝鈴木／司会＝野村」と分けていたが、**分けたことによる連携ミスのほうがリスクが高い**という判断で鈴木が両方持つことにした。司会は本番中に前に立つが、30分前からスタンバイできれば制作の判断も持てる。**判断する人と伝える人が同じ**なので、押し戻しの意思決定が速い。

## 4. 会場レイアウト（701会議室）

### 4-1. 一日をとおして島は動かさない

- 座談会のみ参加の方の席は、ランチ以降は後方に集約する

**前方の構成**：ポータブルステージ上に登壇席、中央に自立式スクリーン100インチ（投影1面）、**その左右に大型モニター2台**。会場が横長で、中央のスクリーン1台だけでは端席から見づらいため。

### 4-2. 島の配置（音対策込み）

**参加者55名・1島5〜6人・全体11島**で組む。劇作家コースは1島5名（倉沢の判断）、演出家コースは定員15名になったため3島。

```
       [ モニター ]  [ スクリーン・登壇席 ]  [ モニター ]

  ┌──────────────┐   ┌──────────────┐
  │  演出（15名）      │   │  劇作（20名）      │  ← 最奥・静かな側
  │  3島               │   │  4島               │
  └──────────────┘   └──────────────┘

              ← 通路を広く空ける（緩衝帯） →

  ┌──────────────────────────────┐
  │      プロデューサー（20名）4島              │  ← 入口側・議論が最も大きい
  └──────────────────────────────┘

          [ 入口・受付 ]
```

- **劇作WS＝静かな執筆** → 入口から最も遠い最奥に
- **プロデューサーWS＝議論＋プレゼン練習で最も音が出る** → 入口側、劇作から対角に
- **演出WS＝議論中心** → 中間
- 劇作／演出とプロデューサーの間に通路を広く取り、**パーテーションを4枚立てる**
- 島は**背中合わせにせず、向きを揃える**（声が互いに正面から飛ばないように）

※ 島の数と配置は赤羽の最終図面で確定する。**備品リストの台数と食い違わないよう、提出前に突き合わせること。**

## 5. 同室並行WSの音対策

パーテーションを借りられるため、島の置き方・遮蔽・運用の3点で組む。ただし「拡声しない」の徹底が引き続き最重要で、ここが崩れると45分間ずっと音量競争になる。

| 優先度 | 対策 | 内容 |
|---|---|---|
| **★最重要** | **拡声しない** | 各WSでハンドマイクを一切使わない。ファシリの地声で届く島間隔にする。**1つでも拡声すると他2本が対抗して拡声する**。ブリーフィングで全ファシリに明言する |
| **★最重要** | **アナウンスは鈴木に一本化** | 「残り5分」等の合図は鈴木が1回だけ全体に出す。各WSが個別に大声を出さない |
| ★ | **物理距離と緩衝帯** | §4-2のとおり、劇作とプロデューサーを対角に置き、間の通路を広く空ける |
| ★ | **パーテーションで区切る** | 三つ折り・キャスター付きを**4枚**、島の間に立てる。ホワイトボードの併用も検討 |
| — | **廊下には逃がさない** | 廊下・ホワイエは**会場としては使えない**。WSはすべて701会議室の中で完結させる |
| ○ | **劇作WSの設計を音前提にする** | 阿部さんに「周囲に音がある環境での執筆」を前提に進め方を組んでもらう |
| — | **BGMは流さない** | マスキング目的のBGMは、かえって全体の声量を上げるため使わない |
| ★ | **リハで検証** | 仕込み時（09:50–10:00）に各島で通常の声量で話し、被り具合を実地確認する。**結果を見て島の距離・向き・立ち位置を微調整する** |

### 6-3. 配置上の注意点

**① 司会と制作統括を鈴木が兼務する**（9/11に変更）
v0.8までは「統括＝鈴木／司会＝野村／タイムキープ＝横堀」と3つに分けていたが、**分けたことによる連携ミスのほうがリスクが高い**という判断で、鈴木が司会と統括の両方を持つ形に変えた。司会は30分前からのスタンバイで足り、本番中に前に立っている時間も長くはない。**判断する人と伝える人が同じ**になるので、押し戻しの意思決定が速くなる。横堀は座談会のキュー出しと講師アテンドに専念する。

**② 映像・接続は大野に集約する**（9/11に変更）
大野が大型モニターの手配窓口を持つことになったため、**登壇資料の集約・スライド出し・PC操作・会場オペとの連携**を大野に寄せた。投影資料は事前に1台のPCへ集めておく。赤羽は当日プロデューサー座談会のモデレーターとWS進行に入るため、機材は持たせない。

**③ 受付は遠藤が責任者**（9/11に変更）
鈴木が司会へ、大野が映像へ回ったため、受付の現場判断者が空いた。遠藤は当初お弁当の会計業務を想定していたが集金が無くなり役割に余裕があるため、受付責任者を担う。**座談会中も受付に常駐**し、途中入退場と繰り上げの受け入れに対応する。

**④ 佐々木は「オペする人」ではなく「オペに伝える人」**
実オペは会場PA／映像オペが担う。佐々木の仕事は登壇席の転換とキューの伝達。**進行表を会場オペと事前に共有しておく**ことが前提になる（§8）。

**⑤ 鈴木を遊撃に回せる**
劇作WSに阿部さんが入るため、鈴木はWS中は3WS巡回・遊撃に専念できる。同室並行で最も読めないのが音とグループ分けの混乱なので、**動ける人が1人いる**のは大きい。

**⑥ 撮影NG者の情報は受付から3方向へ**
受付（遠藤・佐々木）→ 外注カメラマン、野村、鈴木。カメラマンが10:05のブリーフィングに同席するので、そこで運用を確定させる。
