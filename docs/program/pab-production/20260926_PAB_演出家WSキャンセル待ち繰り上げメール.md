## この文面の考え方

**「定員を増やしました」を先に、「ご参加いただけます」を後に置きました。** 逆にすると、誰かが辞退した結果に見えます。**こちらが枠を広げた**という事実を先に置くほうが、受け取る側は素直に喜べます。

**返信期限に理由を添えました。** 「9月18日まで」とだけ書くと催促に見えますが、「お弁当の数を確定させるため」と一言あるだけで、こちらの都合をお願いしている形になります。

**辞退の返信もしやすくしました。** 「ほかにお待ちの方へお席をお譲りできます」と書くことで、断ることが誰かの役に立つ、という形にしています。返信が来ないのがいちばん困るので、**どちらの返事も同じくらい歓迎している**と伝わるようにしました。

**当日の詳細は書きすぎていません。** 確定後に改めて案内を送る前提なので、ここでは「行けるかどうかを判断できる情報」だけに絞っています。
