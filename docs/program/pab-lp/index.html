About

SEEDについて

SEEDは、舞台をつくる仕事をめざす人のための学びの場をつくっています。日本で生まれた作品を世界に届けられる人を育てたい、というのが出発点です。

劇作家・演出家・プロデューサーの3職能を対象に、国際的に通用するスキルとマインドセットを備えた人材を育成するためのプログラムを開発しています。この一年は、国内外の現場をまわるリサーチを重ねてきました。

9月26日は、その成果を交えた座談会、実際に手を動かすワークショップ、そして今後のプログラムをご案内する説明会の3つを、一日で行います。

学校・部活動・ゼミなどでのご紹介も歓迎しています。

Performing Arts Base 2026 とは

東京都などが主催する「東京舞台芸術祭 2026」のショーケースイベントです。演劇・ダンス・大道芸などジャンルを越えたアーティストが集まり、各作品のエッセンスを約20分に凝縮したパフォーマンスやトークショーを上演します。SEEDのこの一日も、そのプログラムのひとつとして開催します。

会場では、SEEDの講座のほかにも一日を通してさまざまな舞台芸術を無料で自由に鑑賞できます。行き帰りの時間に、気になる公演を覗いてみてください。

FAQ

よくある質問

演劇の経験がなくても大丈夫ですか？
はい。初めての方を前提に設計しています。専門用語の予習も不要です。
一人で参加しても大丈夫ですか？
一人参加の方が多い想定です。ワークショップは当日その場でグループを組むので、心配いりません。もちろん、友達との参加も歓迎です。
座談会だけ、ワークショップだけの参加もできますか？
できます。申込時に、参加したいプログラムをお選びください。
途中入場・途中退出はできますか？
できます。受付でスタッフにお声がけください。
服装や持ち物の指定はありますか？
服装は自由です。持ち物は筆記用具のみ（紙は会場でご用意します）。プロデューサーのワークショップに参加する方は、プレゼンテーション機能（PowerPoint・Keynoteなど）のあるパソコンがあると望ましいですが、必須ではありません。
参加に年齢制限はありますか？
座談会と説明会は、どなたでも参加できます。ワークショップのみ25歳までの方が対象です（3講座とも同じ）。26歳以上の方も、ワークショップを見学していただけます。
定員はありますか？
ワークショップに定員があります。劇作家 20名／演出家 10名／プロデューサー 20名です。定員に達し次第、受付を終了しますので、参加をお考えの方はお早めにお申し込みください。
会場はどこですか？迷わず行けますか？
東京国際フォーラム（JR有楽町駅より徒歩1分）のガラス棟7階 701会議室です。同じ会場でPerforming Arts Base 2026が開催されているので、館内の案内表示をたよりに7階までお越しください。
SEEDの講座以外にも、会場で何かやっていますか？
はい。同じ会場でPerforming Arts Base 2026が開かれていて、演劇・ダンス・大道芸などのパフォーマンスを一日中、無料で自由に鑑賞できます。講座の前後にぜひ立ち寄ってみてください。
お昼ごはんはどうすればいいですか？
お弁当を参加者全員にご用意します（無料）。持ってくる必要はありません。ランチの時間は講師陣が各テーブルに分かれて参加者と交流するので、ぜひこの時間もご参加ください。
申込後に参加できなくなった場合は？
SEED事務局（seed@jpasn.net）までキャンセルのご連絡をお願いします。
