## 1. リサーチ全体像（AB報告の骨格＝スライド1枚目の中身）

```
フェーズ0：海外インデプスインタビュー（定性）  ── 完了へ
  2025年度 7名（小栗・阿部・上田・小山・田中・前川・小嶋）
  2026年度 3名（井川／NY・時田／ロンドン・小川／NY）
  → 9/18 小川さん報告会をもって 計10名分が揃う ＝ フェーズ0クローズ

フェーズ0.5：国内関係者からのフィードバック取得（新設）  ── 9/18以降
  守秘義務付き限定公開 → 所定フォーマットで示唆・コメントを回収
  対象：アドバイザリーボード5名 ＋ JPASN正会員の希望者

フェーズ1：客観データによる検証（定量・悉皆）  ── 8月着手
  1-A 大学シラバス調査（国内：悉皆／海外：ロンドン・NY・ソウルの主要校）
  1-B モデルケース選定と深掘り（ノンバーバル／IP展開／ファインアートの3ジャンルにて）
      → ケースの「源泉」を特定（必ずしも教育機関とは限らない）
      → 源泉が教育機関でない場合はその機関を直接リサーチ（例：RSC、ディズニー）

フェーズ2：To-be／As-Is の差分確定 → 人材要件・カリキュラムへ反映
```

**この構成が福井先生へのアンサーになる理由**：フェーズ0（人が語った情報＝歪みを含む定性）を、フェーズ1（公開シラバス＝客観的・悉皆的なデータ）で検証する二層構造であることを示せる。

## 4. AB向けスライド骨子案（2〜3枚）

### スライド1：リサーチ全体計画とフェーズ0の完了
- 縦軸にフェーズ0 → 0.5 → 1 → 2、横軸に時間（2025年度〜2026年度）のロードマップ1枚。
- フェーズ0＝**海外インデプスインタビュー計10名／9月18日をもって完了**を明示（数字を出す）。
- フェーズ0は「定性・仮説形成」、フェーズ1は「客観・悉皆」と**性質の違いを図で示す**（＝福井先生への回答が図で伝わる構造にする）。

### スライド2：フェーズ0成果物の取扱い方針
- 3層で整理：**①音声ローデータ＝非公開**（将来は公開前提の新規収録＝ポッドキャストへ）／**②報告書＝守秘義務付き限定共有**（Box表示のみ・所定フォーマットでのフィードバック提出が条件）／**③統合成果＝人材要件・カリキュラムとして公表**。
- 「事業の方針決定のために収集したデータである」という原則を1行で明記。
- フェーズ0.5（国内関係者からのフィードバック取得）を**新しい価値のある工程**として提示する。「出せません」ではなく「一緒に読んで示唆をください」の建て付けにする。

### スライド3：今後のリサーチ計画（大学シラバス調査・モデルケース）
- 2本立てを並置：**(左) 国内＝悉皆／(右) 海外＝主要校＋モデルケース起点**。
- 国内は「対象◯校・2019年以降のシラバスは公開されており取得可能・◯月完了予定」と**数字とスケジュール**を入れる（福井先生への直接のアンサー）。
- モデルケースは3ジャンルの枠組みと、**「源泉は必ずしも教育機関ではない」という仮説**を明示。
- アジア（韓国・台湾）を対象に含めていることを明示（第4回で奥山先生・福井先生から指摘済み）。
