# SEED デザインシステム

> **これは SEED の制作物全般（Web・スライド・配布物）に共通する基準です。**
> ロゴから導出したブランド基盤を定義し、媒体ごとの適用方法を示します。
>
> - **策定根拠**：SEEDロゴ（`docs/program/pab-lp/seed-logo.svg`）と、2026年9月26日 PAB告知ページの制作過程で確定した方針
> - **実装リファレンス**：`docs/program/20260926_PAB_SEEDオープン講座_告知ページ_v3.html`（全トークンをCSS変数として実装済み）
> - **PPT向けの詳細**：`docs/SEED_PPTデザインシステム.md`（本書に準拠。スライド固有の実装を担当）
>
> **配色は白＋グレー階調で確定しています**（2026年8月決定）。過去資料の緑基調は使いません。経緯は「9. 配色の決定と経緯」を参照。

---

## 1. ブランドの基盤

SEEDのロゴは **グレーの2つの曲線的な形** と **幾何学サンセリフの「Seed」** でできています。デザインシステムはこの2要素から導出します。

| ロゴから読み取る性質 | デザインへの反映 |
|---|---|
| 無彩色（グレー1色） | **色で主張しない。** 白地とグレー階調で構成する |
| 曲線・角のない形 | **角丸を全要素に適用する。** 直角の箱を並べない |
| 幾何学サンセリフ | 欧文・数字は幾何学サンセリフ。明朝は使わない |
| 余白の多いロックアップ | 余白を詰めない。要素間にゆとりを持たせる |

**トーン**：誠実・洗練・静か。舞台芸術の専門家が見ても違和感がなく、同時に高校生が読んで硬すぎないこと。

## 2. カラー

### 基本原則

**白地＋グレー階調のみで構成する。** アクセントカラーを持ちません。情報の区別は「色相」ではなく **グレーの階調・罫線・余白・角丸** で行います。

これは制約ではなく判断です。3職能（劇作家・演出家・プロデューサー）に色を割り当てると序列や属性の誤読が生じるため、**番号と英字ラベルで区別する**方式を採用しています。

### トークン

| 役割 | 変数名 | HEX | 用途 |
|---|---|---|---|
| 地 | `--ground` | `#FFFFFF` | 基本の背景 |
| 淡い面 | `--ground-2` | `#F4F5F6` | 1つおきのセクション、ラベルのピル、写真枠。**ロゴ台紙と同じグレー** |
| 面 | `--surface` | `#FFFFFF` | カード・モーダルの地 |
| 本文 | `--ink` | `#1A1C1E` | 本文・見出し。**純黒は使わない** |
| 補助文字 | `--ink-2` | `#5F6469` | 説明文・キャプション |
| 微弱文字 | `--ink-3` | `#9AA0A5` | 注記・ラベル |
| ロゴグレー | `--mark` | `#AEB2B5` | 番号・装飾の小要素。**ロゴマークと同じ色** |
| 罫線 | `--line` | `#E3E5E7` | 区切り線・カード枠 |
| 罫線（強） | `--line-2` | `#CFD2D5` | 内側のセル枠 |

### 明暗の扱い

**単一デザインに固定し、ダークモードで反転させません**（`color-scheme: only light`）。告知物として配色が環境で変わることを避ける判断です。

### 例外：状態を示す色（内部資料のみ）

進捗表・ダッシュボードなど **状態を機械的に判別する必要がある場合に限り**、以下を使えます。**ブランドのアクセントカラーではなく、機能的な記号**として扱ってください。

| 意味 | 文字・線 | 背景（淡色） |
|---|---|---|
| 完了・良好 | `#2E7D32` | `#E8F5E9` |
| 課題・警告 | `#C00000` | `#FCDCDC` |
| 進行中・補足 | `#E97132` | `#FAE2D5` |
| 情報・参照 | `#0070C0` | `#EAF3FB` |

**使用条件（すべて満たすこと）**

- 対外広報物（Webページ・学生向け配布物・SNS）では **使わない**
- 「状態」以外の用途（装飾・分類・強調・グラフの色分け）では **使わない**
- 1つの画面・スライドで使う色は原則1系統に絞る
- 色だけで意味を伝えず、必ずラベル文字を併記する（色覚特性への配慮）

### 例外：職能識別色（内部ダッシュボードのみ）

**SEEDダッシュボード（`dashboard/template.html`）に限り、3職能を色で識別することを認めます。**
2026年9月2日、ダッシュボード刷新の検討にあたって下した判断です。

| 職能 | 文字 | 背景（淡色） |
|---|---|---|
| 劇作家 | `#C25219` | `#FEF3E2` |
| 演出家 | `#5C3D9E` | `#F0EDFD` |
| プロデューサー | `#1D9E75` | `#E1F5EE` |

原則（2章「基本原則」）は、序列や属性の誤読を避けるため職能に色を割り当てず、番号と英字ラベルで区別することです。
ただしダッシュボードでは、進捗表・関係者マップ・タイムラインの一覧性をこの3色が支えているため、**原則より実用を優先しました。**

**使用条件（すべて満たすこと）**

- 対外広報物（告知ページ・学生向け配布物・SNS・スライド）では **使わない**。原則どおり番号＋英字ラベルで区別する
- 内部ダッシュボードでも色だけで職能を伝えず、必ず職能名を併記する（色覚特性への配慮）
- 3色は同じ明度・彩度帯にそろえ、職能に序列や優劣を読ませない

### 例外：事業ラインの識別色（内部ダッシュボードのみ）

**SOIL と SEED のどちらの事業の話かを示す色**も、内部ダッシュボードに限り認めます。装飾ではなく、
タスク・カード・図版がどちらの事業に属するかを示す機能的なラベルです。

| 事業 | 文字 | 背景（淡色） |
|---|---|---|
| SOIL | `#085041` | `#E1F5EE` |
| SEED | `#0C447C` | `#E6F1FB` |

使用条件は職能識別色と同じです。対外広報物では使いません。

> **既知の重なり**：SOIL の色（`#1D9E75` 系）と職能識別色のプロデューサー（`#1D9E75`）は同値です。
> 出てくる文脈が違うため実害は出ていませんが、両方が同じ画面に並ぶ図版をつくるときは注意してください。

### UIの選択・強調について

ダッシュボードの**選択状態・ホバー・主ボタンは、色ではなく墨（`#1A1C1E`）で示します。**
以前は青（`#378ADD`）をUIのアクセントに使っていましたが、2026年9月2日にすべて墨へ寄せました。
青は「SEED事業を指すラベル」としての用途だけに残しています。

## 3. 角丸（曲線）

ロゴの曲線に呼応させ、**4段階**で運用します。直角（0px）は使いません。

| 変数名 | 値 | 適用対象 |
|---|---|---|
| `--r-pill` | `999px` | ラベル・タグ・チップ・閉じるボタン |
| `--r-sm` | `12px` | ボタン・小さなセル・リスト項目 |
| `--r-md` | `18px` | カード・グリッド・モーダル・写真枠 |
| `--r-lg` | `28px` | セクションのパネル |

**PPTでの換算**：PowerPointの角丸四角形は「半径＝短辺に対する比率」で指定します。`roundRect adj` は要素サイズにより変わるため、**実寸で 12pt / 18pt / 28pt 相当**になるよう都度調整してください。ピルは `adj=50000`（最大）。

## 4. タイポグラフィ

### 書体

| 用途 | 指定 |
|---|---|
| 欧文・数字（表示用） | **Futura → Century Gothic → Avenir Next → Trebuchet MS** の順で継承。幾何学サンセリフ |
| 和文 | **Hiragino Kaku Gothic ProN → Hiragino Sans → Yu Gothic → Meiryo** |
| 明朝体 | **使わない**（ロゴが幾何学サンセリフのため） |

### 使い分けの原則

- **欧文ラベル・時刻・数字は表示用書体＋広いレタースペーシング**（`.14em`〜`.20em`）。ロゴの「SEED」のトラッキングに合わせる
- **和文の本文はゴシック体で標準のレタースペーシング**。可読性を優先
- 数字が縦に並ぶ箇所（時刻・料金）は **`font-variant-numeric: tabular-nums`**（PPTでは等幅数字を選択）

### 日本語の改行制御（Web固有・重要）

- `word-break: auto-phrase` で文節単位の折り返しにする
- 見出しは分節を `white-space: nowrap` の `<span>` で囲み、**「仕/事」のような単語の分断を防ぐ**
- `text-wrap: balance` を見出しに適用

## 5. レイアウト

| 項目 | 方針 |
|---|---|
| 設計順序 | **モバイルファースト。** 375px幅を基準に組み、40rem / 54rem で段階的に拡張 |
| コンテンツ幅 | 最大 62rem（約990px） |
| 画面端の余白 | モバイル 1.15rem ／ タブレット以上 1.6rem |
| 区切り | **1つおきにセクションの地色を変える**（白 ⇄ `--ground-2`）。角丸28pxのパネルが積み重なって見える |
| セクション見出し | 英字キッカー＋和文見出し＋伸びる罫線。キッカーの手前に短い丸バー（ロゴグレー）を置いて起点を示す |
| 横スクロール | **絶対に発生させない。** 幅の広い要素は個別に `overflow-x: auto` |

## 6. コンポーネント

### ラベル（ピル）
角丸最大＋`--ground-2`の塗り、または`--line-2`の枠線。欧文は大文字＋広いレタースペーシング。**「これは項目名である」ことを示す**役割。

### カード
`--surface`の地＋`--line`の枠＋`--r-md`の角丸。グリッドの隙間を`--line`色の1pxにして、枠線を共有させる（`gap: 1px` + 親要素に背景色）。

### 定義リスト（項目＋内容）
**1項目＝1ブロックとして罫線で区切る。** 項目名はピルラベル、内容はその下。`dt`/`dd` を `<div>` でグループ化して余白と罫線を制御します。

### 番号
`01` `02` `03` を表示用書体・`--mark`色で。**順序に意味がある場合のみ**使用（SEEDでは発表順＝劇作家→演出家→プロデューサー）。

### モーダル
モバイルは下から出るシート（下側の角丸なし）、デスクトップは中央配置（全角丸）。`isolation: isolate` と影で浮かせる。**フォーカストラップ必須**。

### 影
浮いている要素にのみ、`rgba(26,28,30,.09)` のごく淡い影。立体装飾はしない。

## 7. モーション

- **`transform` と `opacity` のみ**をアニメーションさせる（コンポジタ処理でカクつかない）
- スクロール連動は **CSSのview timeline**（`animation-timeline: view()`）。JavaScriptでスクロール位置を監視しない
- `@supports` で囲み、未対応ブラウザでは静止状態で表示
- **`prefers-reduced-motion: reduce` を必ず尊重する**
- `transition: all` は使わない。プロパティを明示する

## 8. 言葉づかい

Web・スライド・配布物すべてに共通します。PAB告知ページの制作で繰り返し修正した実績に基づく方針です。

| 原則 | 具体例 |
|---|---|
| **事業側の言葉を学生の言葉に翻訳する** | ×「基盤の形成を目的として人材育成プログラム開発を推進」 ○「舞台をつくる仕事をめざす人のための学びの場をつくっています」 |
| **同じものを2つの名前で呼ばない** | 「リサーチ報告会／プレ講座」と「座談会」を混在させない。用語を1つに統一する |
| **条件は具体的に書く** | ×「対象年齢に当てはまらない方」 ○「26歳以上の方」 |
| **同じ条件を各項目に反復しない** | 3講座すべて同条件なら、1回だけ述べる |
| **数字は明示する** | 定員・時刻・料金・締切をぼかさない |
| **職能の並び順は発表順** | 劇作家 → 演出家 → プロデューサー（作品ができていく順） |
| 見出しは体言止めか短い言い切り | 「一日の流れ」「参加方法」「こんな人に来てほしい」 |

## 9. 配色の決定と経緯

**SEEDの配色は、媒体を問わず「白＋グレー階調」を正とします。**（2026年8月 決定）

### 決定の理由

SEEDロゴが無彩色であり、これに整合させることをブランドの基盤としたため。対外広報物と内部資料で見た目が分かれないよう、**全媒体に同じ基準を適用**します。

### 過去資料との関係

第3回アドバイザリーボード資料までは **ディープグリーン `#284E3F` を基調**とした配色が使われていました。これは**ロゴ確定前の実績値**であり、**今後の新規制作では使いません**。

| | 旧（〜第3回AB資料） | **現行** |
|---|---|---|
| 基調色 | ディープグリーン `#284E3F` | **なし（白＋グレー）** |
| アクセント | ティール `#0D9488` | **なし** |
| 欧文書体 | Arial | **Futura / Century Gothic** |
| 角丸 | 中程度・任意 | **4段階・必須** |

過去資料を改訂する場合は、緑を本書のグレー階調に置き換えてください。既存資料をそのまま再利用する分には、無理に遡って修正する必要はありません。

`docs/SEED_PPTデザインシステム.md` は本書に合わせて改訂済みです（スライド固有の実装詳細を担当）。
